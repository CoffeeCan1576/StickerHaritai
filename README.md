UnityのAR Mobileテンプレートをベースにプロジェクトを作成し、既存のAR機能を活用しながら、iPhone内の写真を現実空間にステッカーのように配置できるARアプリへと改造した。

まず、テンプレートに用意されていたカメラやAR空間の認識機能を利用し、iPhoneのカメラ映像を背景として表示しながら、現実空間の平面を検出し、その位置にオブジェクトを配置できる構成を確認した。

次に、既存のキューブなどを配置する機能を変更し、iPhoneの写真ライブラリからユーザーが選択した画像を読み込んで、AR空間に平面状のオブジェクトとして配置する機能を追加した。

写真の選択には、iOS端末の写真ライブラリにアクセスするための NativeGallery というライブラリを使用した。
また、AR空間上で画面のタップ位置と現実空間の平面を対応させるために、Unityの AR Foundation が提供する ARRaycastManager を利用した。

AR Foundationは、iPhoneなどの対応端末でカメラ映像や空間認識といったAR機能を扱うためのUnity向けフレームワークであり、端末固有のAR機能をUnityの共通インターフェースから利用できる。

カメラやARセッションの管理には、テンプレートに含まれていた ARSession、XR Origin、Main Camera、AR Camera Manager、AR Camera Background などの構成要素を活用し、平面認識には AR Plane Manager を使用した。

写真を配置する処理は、独自に作成した ARPhotoStickerPlacer.cs というC#スクリプトにまとめ、
写真の読み込み、画像データの取得、配置位置の決定、ARオブジェクトへの画像の反映を連携させた。
また、写真を平面状のオブジェクトに貼り付けることで、単なる立方体ではなく、選択した画像そのものが空間に浮かぶような表示を実現した。
さらに、テンプレートに元からあったキューブの配置機能が写真配置と競合しないよう、既存の Object Spawner を無効化し、写真を配置する機能を中心とした構成に変更した。

アプリの画面については、テンプレートに含まれていたWelcome画面やContinueボタンを活用し、起動後に初期画面からAR機能へ移行できる構成にした。
画面の表示や切り替えにはCanvasなどのUnity UI機能を使用し、ARScreenSwitcher などの既存スクリプトも利用した。


最後に、Unityで作成したプロジェクトをXcode経由でiPhone向けにビルドし、実機上でカメラの起動、写真の選択、AR空間への画像配置まで動作することを確認した。
今回使用した主な技術の役割を整理すると、AR Mobileテンプレートは開発の土台、AR FoundationはAR機能、NativeGalleryは写真ライブラリへのアクセス、C#スクリプトはそれらをつなぐ独自の処理を担当している。AR Foundationの機能はコンポーネント単位で有効化できるため、既存のテンプレートを全面的に作り直すことなく、必要な機能を追加・変更して独自のARアプリへ発展させることができた。

このコードは、iPhoneの写真ライブラリから好きな画像を選択し、その画像をAR空間にステッカーとして貼り付ける機能を実装している。

まず、写真選択ボタンが押されるとiPhoneの写真ライブラリを開き、選択された画像ファイルを読み込んでテクスチャとして保存する。

その後、ユーザーがiPhoneの画面をタップすると、ARで検出した平面上のタップ位置を取得し、その位置と向きに合わせてステッカーを生成する。

ステッカーは写真の縦横比を維持した四角形で構成され、表面と裏面の両方に写真を表示することで、どちら側から見ても画像を確認できるようになっている。

また、UI上のタップではステッカーを配置しないように制御し、写真の読み込みに失敗した場合はエラーを表示する。最後に、オブジェクトが破棄される際にはボタンのイベント登録を解除し、使用した画像データを解放することで、不要なリソースが残らないようにしている。
